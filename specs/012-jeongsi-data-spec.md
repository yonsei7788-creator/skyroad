# 정시 분석 데이터 정의서 (외주 납품 규격)

> 한 줄 요약: 2027학년도 정시 분석 리포트 엔진이 입력으로 받는 두 개의 JSON 파일(전형 시행계획 / 최근 3개년 입결)의 필드 규격과 엑셀 ↔ JSON 매핑 규칙

---

## 현재 상태 — 외주 엑셀 실데이터로 교체됨 (2026-10)

`libs/jeongsi/data/` 의 두 JSON 은 외주 납품 엑셀 `정시_입시자료.xlsx` 에서 **생성한 파일**입니다(§8).
교체 전 추정 샘플은 `libs/jeongsi/__tests__/fixtures/sample-*.json` 에 동결해 테스트용으로만 씁니다.

납품 엑셀은 이 문서 §4 의 3시트 양식이 아니라 **17시트 상세 양식**(대학 반영방법을 원문·구조화 칸으로
모두 기록)으로 왔습니다. 그래서 변환을 두 단계로 나눕니다.

1. 엑셀 → **정규화 원본** `libs/jeongsi/data/source/*.json` — 손실 없이 옮긴다 (§8.1)
2. 정규화 원본 → **엔진 JSON** — 엔진 환산식으로 정확히 재현되는 모집단위만 고른다 (§8.2)

§1~§6 의 필드 규격은 엔진 JSON 의 규격으로 여전히 유효합니다. 실데이터에 맞춰 바뀐 규칙은 §8.3 에 모았습니다.

### 2.3 `formula` — 환산식

#### 2.3.1 구조

| 필드                     | 타입          | 필수   | 허용값 / 규칙                                                       |
| ------------------------ | ------------- | ------ | ------------------------------------------------------------------- |
| `formulaVersion`         | number        | 🔴     | `1` 고정. 스키마 변경 시 상향                                       |
| `totalScore`             | number        | 🔴     | 수능 환산 기준 만점. 예: `1000`, `600`, `800`                       |
| `ratios`                 | AreaRatios    | 🔴     | **합계가 정확히 100**                                               |
| `metric`                 | MetricByArea  | 🔴     | 영역별 활용지표                                                     |
| `inquiryCount`           | number        | 🔴     | `1` 또는 `2`. 탐구 반영 과목 수                                     |
| `convertedStandardTable` | object        | 조건부 | `metric.inquiry === "convertedStandard"` 일 때 **필수**, 그 외 금지 |
| `english`                | EnglishPolicy | 🔴     | 영어 반영 방식                                                      |
| `history`                | HistoryPolicy | 🔴     | 한국사 반영 방식                                                    |
| `bonus`                  | BonusPolicy   | 🟢     | 가산점. 없으면 필드 생략                                            |
| `baseMax`                | AreaBaseMax   | 🔴     | 영역별 기준 만점(정규화 분모)                                       |

#### 2.3.2 `ratios` — 영역별 반영비율

```json
"ratios": { "korean": 35, "math": 35, "english": 3, "inquiry": 27 }
```

| 필드      | 설명                                                               |
| --------- | ------------------------------------------------------------------ |
| `korean`  | 국어 반영비율 (%)                                                  |
| `math`    | 수학 반영비율 (%)                                                  |
| `english` | 영어 반영비율 (%). **[§2.3.4](#234-english--영어-반영) 규칙 필독** |
| `inquiry` | 탐구 반영비율 (%)                                                  |

🔴 **네 값의 합은 반드시 100.** 소수점 허용(예: 33.4)이지만 합은 100이어야 합니다.

#### 2.3.3 `metric` — 활용지표

```json
"metric": { "korean": "standard", "math": "standard", "inquiry": "convertedStandard" }
```

| 필드      | 허용값                                                  |
| --------- | ------------------------------------------------------- |
| `korean`  | `"standard"` (표준점수) \| `"percentile"` (백분위)      |
| `math`    | `"standard"` \| `"percentile"`                          |
| `inquiry` | `"standard"` \| `"percentile"` \| `"convertedStandard"` |

영어는 활용지표가 없습니다(항상 등급 기반). `metric` 에 `english` 키를 넣지 마세요.

#### 2.3.4 `english` — 영어 반영

세 가지 방식 중 하나입니다.

**(A) `ratioIncluded` — 반영비율에 포함 (등급별 환산점수가 총점의 일부)**

```json
"english": {
  "type": "ratioIncluded",
  "scoreByGrade": { "1": 200, "2": 192, "3": 180, "4": 164, "5": 146, "6": 128, "7": 110, "8": 92, "9": 76 }
}
```

**(B) `add` — 가산 (총점에 더함)**

```json
"english": {
  "type": "add",
  "scoreByGrade": { "1": 30, "2": 27, "3": 22, "4": 16, "5": 10, "6": 6, "7": 3, "8": 1, "9": 0 }
}
```

**(C) `subtract` — 감점 (총점에서 뺌)**

```json
"english": {
  "type": "subtract",
  "penaltyByGrade": { "1": 0, "2": 0.5, "3": 2, "4": 4, "5": 6, "6": 8, "7": 10, "8": 12, "9": 14 }
}
```

🔴 **`ratios.english` 와의 정합 규칙 (매우 중요)**

| `english.type`  | `ratios.english` 값                    | 이유                                                      |
| --------------- | -------------------------------------- | --------------------------------------------------------- |
| `ratioIncluded` | `scoreByGrade["1"] / totalScore × 100` | 영어가 차지하는 배점을 비율로 표현                        |
| `add`           | `scoreByGrade["1"] / totalScore × 100` | 가산 최대치를 비율 예산 안에 두어 만점이 총점을 넘지 않게 |
| `subtract`      | **`0`**                                | 감점만 하므로 배점을 차지하지 않음                        |

> 즉 `add` 와 `ratioIncluded` 는 **엔진 계산상 동일**하며, 대학이 시행계획에 "영어 100점 포함"으로 적었는지 "영어 가산점"으로 적었는지를 구분해 보존하는 용도입니다. `ratios.english` 산출 규칙은 두 방식 모두 같습니다.

🔴 **모든 등급 테이블은 `"1"` ~ `"9"` 9개 키를 전부 채워야 합니다.** 대학이 "4등급 이하 동일"로 발표했으면 4~9를 같은 값으로 반복 기재합니다.

#### 2.3.5 `history` — 한국사 반영

```json
"history": { "type": "add", "scoreByGrade": { "1": 10, "2": 10, "3": 10, "4": 9, "5": 8, "6": 7, "7": 6, "8": 5, "9": 4 } }
```

```json
"history": { "type": "subtract", "penaltyByGrade": { "1": 0, "2": 0, "3": 0, "4": 2, "5": 4, "6": 6, "7": 8, "8": 10, "9": 12 } }
```

한국사는 `ratios` 에 자리가 없습니다. `add` 방식이면 환산점수가 `totalScore` 를 **가산 최대치만큼 초과할 수 있습니다** (보통 1% 이내). 정상 동작입니다.

#### 2.3.6 `bonus` — 가산점

```json
"bonus": {
  "mathElective": {
    "미적분": { "type": "percent", "value": 5 },
    "기하":   { "type": "percent", "value": 5 }
  },
  "scienceInquiry": { "type": "percent", "value": 3, "appliesTo": "total" }
}
```

| 경로                                      | 설명                                                           |
| ----------------------------------------- | -------------------------------------------------------------- |
| `mathElective.{확률과통계\|미적분\|기하}` | 해당 선택과목 응시자에게 주는 가산. 적용 대상 과목만 키로 넣음 |
| `.type: "percent"`                        | 수학 환산점수에 `×(1 + value/100)`                             |
| `.type: "point"`                          | 총점에 `+value` (고정 점수)                                    |
| `scienceInquiry`                          | 과학탐구 응시 가산                                             |
| `.appliesTo: "each"`                      | 반영된 과탐 **과목 수만큼** 가산 (2과목이면 `value × 2`)       |
| `.appliesTo: "total"`                     | 과탐을 1과목이라도 응시하면 **한 번만** 가산                   |

가산점이 붙으면 환산점수가 `totalScore` 를 초과할 수 있습니다(최대 5% 정도). **`totalScore` 는 "가산점 제외 기준 만점"입니다.**

#### 2.3.7 `baseMax` — 영역별 기준 만점

정규화 분모입니다. 활용지표에 맞춰 정해야 합니다.

| `metric` 값           | `baseMax` 값                                           |
| --------------------- | ------------------------------------------------------ |
| `"percentile"`        | **`100`** (백분위 만점)                                |
| `"standard"`          | 해당 영역 표준점수 최고점 (국어/수학 `140`, 탐구 `72`) |
| `"convertedStandard"` | **`convertedStandardTable` 의 최댓값과 정확히 일치**   |

```json
"baseMax": { "korean": 140, "math": 140, "inquiry": 75 }
```

영어는 없습니다(`EnglishPolicy` 가 절대 점수를 직접 주므로).

#### 2.3.8 `convertedStandardTable` — 변환표준점수표

```json
"convertedStandardTable": { "0": 20, "1": 20.3, ..., "99": 72, "100": 75 }
```

🔴 **백분위 `0` ~ `100` 정수 키를 101개 전부** 채웁니다. 엔진은 보간 없이 정확 조회만 합니다.
🔴 `metric.inquiry` 가 `"convertedStandard"` 가 **아니면 이 필드를 넣지 마세요.**

### 2.4 `restrictions` — 선택과목 제한

```json
"restrictions": { "math": ["미적분", "기하"], "inquiry": "과탐필수" }
```

| 필드      | 허용값                                          | 의미                                         |
| --------- | ----------------------------------------------- | -------------------------------------------- |
| `math`    | `["확률과통계"]` / `["미적분","기하"]` 등 배열  | **허용되는** 수학 선택과목. 생략 = 제한 없음 |
| `inquiry` | `"과탐필수"` / `"과탐1과목이상"` / `"제한없음"` | 탐구 제한                                    |

제한이 전혀 없으면 `restrictions` 키 자체를 생략합니다. **빈 객체 `{}` 를 넣지 마세요.**

| `cut50`               | ResultCut | 🟡   | 상위 50% 컷. 미공개면 생략                              |                            |
| `average`             | ResultCut | 🟡   | 최종등록자 평균. 미공개면 생략                          |                            |

### 3.2 `ResultCut`

```json
"cut70": { "metric": "percentile", "value": 94.5 }
```

| 필드            | 허용값                               | 의미                                                                                                                                |
| --------------- | ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| `metric`        | `"percentile"` \| `"convertedScore"` | 백분위(국·수·탐 평균) \| 대학 자체 환산점수                                                                                         |
| `value`         | number                               | `percentile` 이면 0~100, `convertedScore` 는 대학 총점 스케일                                                                       |
| `bonusIncluded` | boolean (생략 시 `true`)             | 🔴 컷이 **수학 선택·과탐 가산점을 반영한 값**인지. `metric` 이 `convertedScore` 일 때만 의미 있음. 영어·한국사는 항상 포함으로 간주 |

🔴 **지표 일관성 규칙**

1. 한 레코드 안의 `cut70` / `cut50` / `average` 는 **모두 같은 `metric`** 이어야 합니다.
2. 같은 `planKey` 의 3개년 레코드도 **같은 `metric`** 이어야 합니다. 대학이 중간에 공개 방식을 바꿨다면 가장 최근 방식으로 통일하거나, 환산 불가한 해는 그 레코드를 뺍니다.
3. `convertedScore` 는 **plan 의 `formula.totalScore` 와 같은 스케일**이어야 합니다. 대학이 500점 만점으로 입결을 발표했는데 환산식 총점이 1000이면 환산해서 맞추거나, `percentile` 로 대체합니다.
4. 🔴 **`convertedScore` 컷은 가산점 포함 여부를 확인해 `bonusIncluded` 에 기재하세요.** 대학이 "수능 환산점수" 와 "총점(가산 포함)" 을 분리 공시하는 경우가 있습니다. 어느 쪽인지 모르면 **추측해서 채우지 말고 입학처에 확인**하십시오.

   왜 중요한가: 컷이 가산 **제외** 기준인데 `true` 로 적으면 미적분·과탐 응시자의 점수만 1.6~5% 부풀려 비교되어, **가산 수혜 학생만 선택적으로 합격 가능성이 과대평가**됩니다. 모든 학생이 똑같이 틀리는 것이 아니라 일부만 틀리므로 발견이 어렵고 피해가 큽니다.

   대상은 **수학 선택과목·과탐 가산점**뿐입니다. 영어·한국사는 환산식 구성 요소로 발표되므로 항상 포함으로 간주합니다. `percentile` 컷에는 **해당하지 않습니다** — 백분위는 환산 전 지표여서 가산점 개념이 없으니 `bonusIncluded` 를 생략하십시오.

🔴 **값 순서 규칙**: `cut70 ≤ cut50 ≤ average` (높은 성적이 큰 값). 역전되면 수집 오류입니다.

### 3.3 결측 처리

| 상황                             | 처리                                                      |
| -------------------------------- | --------------------------------------------------------- |
| 70% 컷은 있고 50% 컷·평균 미공개 | `cut50` / `average` 필드 생략                             |
| 70% 컷조차 미공개                | **그 레코드를 넣지 않음** (`cut70` 은 필수)               |
| 특정 학년도 데이터 자체가 없음   | 그 학년도 레코드를 넣지 않음 (3개년 전부 필수 아님)       |
| 신설 모집단위로 입결이 아예 없음 | `admission-results.json` 에 레코드 0건. plan 은 그대로 둠 |
| 충원인원만 미공개                | `additionalPassCount` 필드만 생략                         |

`null` / `""` / `0` 으로 채우지 **마세요.** 결측은 **필드 생략**으로만 표현합니다. `0` 은 "실제로 0명"을 뜻합니다.

샘플 데이터는 이 다섯 패턴을 모두 포함해 엔진의 결측 처리를 테스트할 수 있게 구성돼 있습니다.

## 5. 수집 방법 구분 — '어디가' 자동 수집 vs 수기 확인

### 5.1 대학어디가(adiga.kr) 로 자동 수집 가능

어디가는 "대학·학과별 입시정보"와 "전형계획" 을 공개하며, 아래 필드는 조회·다운로드로 확보할 수 있습니다.

| 필드                                  | 비고                                                     |
| ------------------------------------- | -------------------------------------------------------- |
| `university` / `department` / `group` | 모집단위 목록                                            |
| `quota`                               | 모집인원                                                 |
| `competitionRate`                     | 학년도별 경쟁률                                          |
| `additionalPassCount`                 | 충원인원 (공개 대학만)                                   |
| `cut70` / `cut50` / `average`         | 어디가 "학과별 등급·백분위" 공시. **대부분 백분위 지표** |
| `region`                              | 대학 소재지에서 분류                                     |

⚠️ 어디가 공시 입결의 한계:

- 공시 단위가 **학과 기준**이라 모집군이 분리되지 않는 경우가 있습니다 → 대학 입학처 발표와 교차 확인 필요
- 일부 대학은 **등급만** 공시합니다 → 등급만 있으면 그 레코드를 넣지 않습니다 (백분위/환산점수로 추정 금지)
- 환산점수 입결은 어디가에 거의 없습니다 → [§5.2](#52-대학-입학처-시행계획-수기-확인-필수)

### 5.2 대학 입학처 시행계획 수기 확인 필수

**환산식 전체는 자동 수집이 불가능합니다.** 각 대학 입학처가 발표하는 「2027학년도 신입학전형 시행계획」 및 「정시모집 모집요강」 PDF 를 직접 보고 입력해야 합니다.

| 필드                                      | 출처                                                          |
| ----------------------------------------- | ------------------------------------------------------------- |
| `formula.totalScore`                      | 모집요강 "수능 활용 방법"                                     |
| `formula.ratios.*`                        | 모집요강 "영역별 반영비율" 표                                 |
| `formula.metric.*`                        | 모집요강 "수능 활용지표"                                      |
| `formula.inquiryCount`                    | 모집요강 "탐구 반영 과목 수"                                  |
| `formula.baseMax.*`                       | 모집요강 환산식 분모. **명시 없으면 당해 수능 최고점 사용**   |
| `formula.convertedStandardTable`          | 대학별 **변환표준점수 발표표**. 보통 수능 성적 발표 직후 공개 |
| `formula.english.*` / `formula.history.*` | 모집요강 "영어·한국사 등급별 환산점수표"                      |
| `formula.bonus.*`                         | 모집요강 "가산점"                                             |
| `restrictions.*`                          | 모집요강 "지원자격 / 수능 응시영역 기준"                      |
| `cut70` (환산점수 기준)                   | 대학 입학처 "정시 입시결과" 자료실                            |
| `cut70.bonusIncluded`                     | 입결 자료의 **주석·범례**. 명시가 없으면 입학처에 직접 문의   |

⏱ **변환표준점수표는 시행계획 단계에 없습니다.** 2027학년도 표는 2026년 12월 수능 성적 발표 이후에 공개됩니다. 그 전까지는 직전 학년도(2026학년도) 표를 임시로 쓰고, 공개 후 교체하는 2단계 납품이 필요합니다.

**모집단위 선별**

| 조건                                                        | 이유                                                             |
| ----------------------------------------------------------- | ---------------------------------------------------------------- |
| 2027 모집, 모집군 가·나·다                                  |                                                                  |
| 일반전형 (농어촌·특성화·기회균형·지역인재·실기 등 제외)     | 지원자격이 있어야 하는 전형은 추천 후보가 아님                   |
| 전형요소 수능 **80% 이상**                                  | 서울대(80)·연세대(95) 등 주요 대학 포함. `suneungWeight` 로 표시 |
| 반영영역 방식 = 전영역 필수 또는 해석 가능한 상위 영역 선택 | 한국사·과목 단위·중첩 선택·가산 포함 순위는 미지원 (§8.3.1)      |
| 활용지표 = 표준점수·백분위·변환표준점수                     | 등급점수 미지원                                                  |
| 산출식에 기본점수 상수·순위 규칙·공통 분모가 없음           | 엔진 식은 영역별 선형합                                          |
| 정규화 분모를 확정할 수 있음 (아래 배점 체계)               |                                                                  |
| 가산점이 수학 선택과목·과탐 전체·과탐 2과목 응시 유형       | 사탐 가산·과탐Ⅱ 지정 등은 미지원                                 |
| 표준 카테고리 매칭 성공                                     | 새 카테고리를 만들지 않는다 (§2.2)                               |

**배점 체계** — 엔진 식 `(지표 / baseMax) × ratio% × totalScore` 로 대학 계수를 정확히 맞춘다.

| 체계         | 판정                                              | baseMax                                        | 예                     |
| ------------ | ------------------------------------------------- | ---------------------------------------------- | ---------------------- |
| `percentile` | 국·수·탐 모두 백분위                              | 100                                            | 인천대, 상명대         |
| `fixed200`   | 산출식에 `÷200`, `200점 기준`, `×비율×(만점/200)` | 국·수 200, 탐구 100 (2과목 합÷200 = 평균÷100)  | 부산대, 동국대, 중앙대 |
| `highest`    | 산출식에 `최고점` 분모                            | 국·수 140, 탐구 72 **추정** / 변표는 표 최댓값 | 한양대, 이화여대       |
| `weighted`   | 비율 합 ≠ 100 이고 배율이 원문에 있음             | 계수에 맞춘 값                                 | 고려대, 경북대, 연세대 |

- 영어 가산형이면 국·수·탐 배점 = `(만점 − 영어 최대) × 100 / Σ비율` (한양대 910 → 900, 전남대 1000)
- 원문만으로 해석되지 않는 대학은 `FORMULA_OVERRIDES` 에 근거와 함께 둔다 — 경희대(만점 600, 공식 예시로 확정), 서울대(배율 1, 만점 미공시 → 추정 최고점으로 산출)
- `highest` 체계·서울대는 `confidence: estimated` — 환산점수 입결 비교에 쓰지 않는다

**입결 선별** — 모집단위별로 한 지표만 쓴다(§3.2 규칙 2).

1. **백분위 우선**: 국·수·탐 Y, 영어 N, 최종등록자, 탐구 2과목 평균(미공개면 환산식이 2과목 반영일 때만) → `basis` 생략 = simpleAverage
2. 백분위가 없으면 환산점수: 환산식이 exact·가산점 없음, 지표 만점 = 환산 만점, **그 학년도 반영방법이 2027 과 같은 엔진 식으로 변환될 때만** (2024 반영방법은 원본에 없어 제외)
3. 같은 모집단위·학년도에 행이 여럿이면 계열 표기([인문]/[자연])·전형명으로 하나를 고른다. 못 고르면 그 해를 뺀다

#### 8.3.1 상위 영역 선택 변환 규칙

| 원본 칸           | 엔진 (`ConversionFormula.selection`)                                           |
| ----------------- | ------------------------------------------------------------------------------ |
| `targets`         | `areas` (2개 이상)                                                             |
| `count`           | `rankRatios` 길이. 원본 칸은 3순위까지라 4순위는 규칙 원문 "35/30/20/15%" 에서 |
| `rankRatios`      | 배점 체계가 원본 비율을 엔진 비율로 바꾼 배수를 똑같이 곱한다                  |
| `rankBasis`       | 표준점수 → `standard`, 백분위 → `percentile`, 영역 환산점수 → `areaScore`      |
| 대상 영역 `ratio` | 비어 있다. 순위별 비율을 대상 영역 순서대로 채운 자리값을 넣는다               |

제외: 규칙 원문에 한국사·제2외국어·한문·가산·탐구1/탐구2·묶음·"1순위 제외"·나머지·"필수 미반영"·또는,
`rankBasis` 가 등급, 표준점수 기준인데 대상에 영어·비표준점수 영역, 영어가 대상인데 비율포함이 아님,
가중치형인데 대상 영역의 지표 만점이 다름, 대상 영역에 취득점수 기준 가산.

`FORMULA_OVERRIDES` 추가: 서강대(가중치형 배율 1, 영어·한국사 배율 후 가산),
경일대(배율 전 가감 배율 0.9 — 400점 기준 합 × 0.9 구조. 이전 변환은 3.6 을 곱해 간호학과가 틀렸다).

### 8.5 외주업체 확인 요청 항목

변환 중 원본끼리 어긋난 곳입니다. 납품 수정 또는 확인이 필요합니다.

- **건국대 `탐구 2과목 처리` = 평균** — 입결 역산(백분위 85 → 666.5, 공시 666.51)으로는 2과목 **합**이다
- **충남대 공식 예시** — "한국사1 → −1" 이지만 한국사 감점표상 −1 은 4~6등급
- **광운대 공식 예시** — 한국사 가산 제외 금액("가산점 미포함")이다. 예시 표기 통일 필요
- **동양대 공식 예시** — "영95(1등급→백분위95)" 이지만 영어 환산표는 1·2등급 100, 3등급 95 다. 표와 예시 중 하나가 틀렸다
- **성균관대 가산점** — 과탐·미적분 가산 비율이 `미공개`. 공개되면 나군 백분위형 모집단위를 넣을 수 있다
- **경희대·서울대·홍익대·동의대 등 `수능 환산 만점` = 해당없음** — 산출식상 만점이 있다(경희대 600)
- **고려대 의학과·의예과** — 같은 모집단위가 두 이름(KU-076, KU-336)으로 들어 있다
- 모집단위명 중복 표기(예: "자유전공학부 자유전공학부")
